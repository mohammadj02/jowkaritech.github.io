Slow Windows 11? Start With These Checks

A safe first pass for a slow Windows 11 computer, with clear points to stop before risking files.

JowkariTech support notes · Updated 2026-10-15 · General guidance; a specific diagnosis may need an appointment.

First, describe the slowdown

Is only one application slow, or does everything feel delayed? Note when it began and whether there was a recent update, installation or storage warning. This small distinction is useful: an entire computer freezing needs a different investigation from a slow website.

Try low-risk checks first

Save your open work, close unused applications and restart normally. Look at Task Manager with Ctrl + Shift + Esc to see whether memory, CPU or disk usage stays high. Observe before ending unfamiliar processes. Check Settings → System → Storage; review any proposed cleanup rather than deleting personal files blindly. Use Windows Update and Windows Security, not an unsolicited driver updater or registry-cleaning download.

Make one change, then compare

Keep a brief note of the symptom before each change. Reopen the same application and repeat the same task. Changing many settings together can hide what helped and makes reversal harder. Do not disable a workplace security tool, uninstall a business application or erase a drive to make a test faster.

When to stop

Stop routine performance experiments if the machine repeatedly crashes, makes unusual drive noises or loses files. A current backup matters more than a quick benchmark. Physical faults and recovery work are not reliably solved by a general remote session.

Prepare a useful support request

Share the Windows version, the task that feels slow, when it started and whether you still have internet access. Do not send a Task Manager screenshot containing private filenames or an entire event-log dump. A simple description can be enough for the first suitability review.
