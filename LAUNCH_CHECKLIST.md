# JowkariTech launch checklist

Upload these files to the repository root:
- index.html
- styles.css
- app.js
- sitemap.xml
- robots.txt
- 404.html
- all ai-receptionist-*.html files

Keep these existing files:
- CNAME
- JowkariTech logo.png
- the existing Google Search Console verification file

After upload:
1. Open https://jowkaritech.com in an incognito window.
2. Test the interactive demo buttons.
3. Test the email form on desktop and mobile.
4. Test the text link on a phone.
5. In Google Search Console submit https://jowkaritech.com/sitemap.xml
6. Request indexing for the homepage and each niche landing page.
7. Do not add fake testimonials, fake reviews, or fake customer counts.
8. After the first real customer, add a real case study with permission.
9. Add analytics only after choosing the analytics provider you want.

The site is designed to improve clarity and conversion. It cannot guarantee revenue or an 80% success rate; traffic and customer acquisition still matter.
