02 / COLUMN MAPPING

Tell us what each column means.

Suggested mappings are only suggestions. Select a selling price, not wholesale cost. Variants need an explicit product-group ID; similar names are never grouped automatically.

Currency is a review note, not a CSV currency column. Your store must use that currency. No exchange-rate conversion is performed. Numeric Excel identifiers are blocked: recover them as actual text and check leading zeros.

Save mapping stores only these headers and settings in this browser, never product rows. Use Forget mapping to remove it.

    HONESTLY LIMITED, DELIBERATELY USEFUL

    One job.
    Done with care.

    This first version supports new draft products with text SKUs, plain-text descriptions, up to three options and one supplied HTTPS product-image URL per row. Groups are limited to 100 variants.

    No PDFs, legacy XLS, formulas, merged cells, image scraping, inventory sync, store updates, currency conversion or automatic product claims. Columns you do not map are excluded.

    Not Shopify-certified or affiliated with Shopify. Output follows the documented CSV fields, but real-store import testing is still required.

    Shopify’s CSV specification ↗

    Your data stays with you.

    Files are read in browser memory. There is no upload API, AI call, account, tracking pixel or server-side file storage. The hosting provider still processes ordinary connection metadata when serving the app.

    Reloading or clearing removes the file from the app’s working state. Downloads remain on your device. A saved mapping contains header names and settings, so only save it on a trusted device.
